# 植物大战僵尸 · 花园守卫

一个全新的中文单人植物塔防游戏，使用 Tauri 2、TypeScript、Vite 6 和 Canvas 2D，提供波次闯关、无尽生存、四档难度和随机强化。

本目录包含完整的游戏代码、桌面配置、图片、动画及音效，可以单独复制、开发和打包。安装依赖后即可启动，无需其他项目目录，也无需执行素材导入脚本或安装 Python。

界面采用暖白、森林绿与阳光金色，建议窗口尺寸为 **1440 × 940**，桌面窗口最小 **1050 × 760**。战场使用原版 900 × 600 坐标与 5 行 × 9 列草坪，随窗口等比缩放并适配屏幕 DPR。

## 运行环境

- Node.js **20.19+ 或 22.11+**，使用与当前 Vite 6 工程兼容的版本，附带 npm。
- 桌面开发需要稳定版 Rust，目标工具链为 `x86_64-pc-windows-msvc`。
- Windows 上安装 Visual Studio 2022 Build Tools 的“使用 C++ 的桌面开发”，包含 MSVC 和 Windows 10 / 11 SDK。
- 安装 Microsoft Edge WebView2 Runtime；Windows 11 通常已自带，Windows 10 需要确认。
- 普通浏览器预览只需 Node.js 与现代浏览器，不需要 Rust / MSVC。

首次安装 npm、Cargo 依赖及系统运行时需要联网。依赖下载齐全后，游戏素材随程序本地加载，游玩不依赖网络；后续离线构建仍要求所需依赖与工具链已缓存。

在本项目目录打开终端：

```powershell
npm install
```

运行 Tauri 桌面开发版：

```powershell
npm run tauri dev
```

仅在浏览器预览：

```powershell
npm run dev
```

打开终端显示的地址，默认 `http://127.0.0.1:1446`。请通过开发服务器访问，不要直接双击 `index.html`；动画清单和素材需要正常的资源路径。

构建 Windows 桌面应用：

```powershell
npm run tauri build
```

打包产物位于 `src-tauri/target/release/bundle/`。构建会调用前端构建，再编译 Rust 桌面宿主；需要完整的 Windows 开发工具链。

**当前交付没有自动运行依赖安装、构建、类型检查、测试、lint 或应用启动，不表示这些验证已通过。** 上述命令由使用者在需要时执行。

## 怎样守住花园

1. 在首页选择“花园闯关”或“无尽生存”，再选择难度。模式与难度在本局中固定。
2. 从九种植物中带上六种，点击已选植物可取消，再补充新伙伴。“推荐阵容”会恢复向日葵、豌豆射手、坚果墙、寒冰射手、樱桃炸弹、土豆地雷。选中顺序对应快捷键 1～6。
3. 在整备时间布阵，点击天降或向日葵产出的阳光收集资源。选择卡片，再点草坪空格种植；阳光足够、卡片冷却结束且格子为空时才能种下。
4. 通过顶部工具切换 1× / 2× 速度、暂停或铲除。铲除不退还阳光。准备好后可跳过开局和波间整备。
5. 每行拥有一次性割草机。僵尸越过防线即失守；每波必须完成出兵并清除全部僵尸，才进入下一波。

闯关模式共 **12 波**，清完第 12 波获得胜利。无尽模式持续增加压力，并记录最高波次与得分。每 3 波是精英压力波，侧栏显示波次预告、剩余出兵预算与已获得强化。

闯关清完第 3、6、9 波，无尽每清完 3 波，可从三个不同强化中选择一个。强化仅在本局有效，并有叠加上限；专属强化会按照携带的植物过滤。成长强化达到上限后，以阳光补给、存活植物修复或下一波伤害提升补足选择。闯关最终胜利后直接结算。

暂停、强化选择、游戏说明和离局确认期间，模拟与动画时钟停止，植物生长、冷却、阳光和敌人不会暗中推进。切后台或窗口失焦会自动暂停，重新回到窗口后需要点击“继续守护”或按空格。关闭游戏说明或离局确认后，也需主动恢复对局。

未完成的对局返回菜单时，先显示自定义确认面板；确认后以失守结算并记录本局成绩。结算可以按相同阵容重开，或返回菜单重新选择。当前不提供对局中途存档。

| 豌豆射手 | 100 | 5 秒 | 每 1.4 秒发射豌豆，单发 20 伤害 |
| 坚果墙 | 50 | 15 秒 | 1800 基础生命，保护后排 |

## 快捷键

| 操作 | 快捷键 / 鼠标 |
| --- | --- |
| 选择对应植物卡 | `1`～`6` |
| 选择铲子 | `Q` |
| 暂停 / 主动继续 | `空格` |
| 取消选卡或铲子 | `Esc` / 鼠标右键 |
| 关闭说明或取消离局确认 | `Esc` |
| 收集阳光、种植、铲除 | 鼠标左键 |
| 切换 1× / 2× | 点击顶部速度按钮 |

植物操作只在开局整备、战斗和波间整备期间生效。弹层打开时不能穿透操作战场。键盘可以通过 Tab 在操作按钮间移动。

## 本地记录与资源加载

- 声音设置、总局数和最佳成绩会在本地保存，成绩按 **模式 × 难度** 分为八类，首页可查看对应记录及全部分类。
- 桌面版通过 Tauri 将数据保存在应用数据目录，浏览器预览使用当前站点的 localStorage。两者的记录彼此独立。
- 每局胜利、失守或主动结束只记录一次。读取失败仍允许使用默认设置游戏；保存失败会显示中文提示，当前会话可以继续。
- 启动先显示素材加载进度。资源失败会显示原因和“重新加载”按钮，在素材及本地设置准备完成前不能开局。
- 若浏览器禁止本地存储、磁盘不可写或应用数据目录缺少权限，最新成绩与设置可能不能持久保存。
